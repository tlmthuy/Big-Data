1. **27/11 requirement not met yet:** the Recommendation tab has no real predictions. This is blocked on TV2/TV3 (prediction files and catalog), not on TV4.

All TV4 fixes are small (S) or medium (M) and can be done on 26–27/11.

## 5. Top 5 risks for demo day

1. **No real recommendations (⛔).** The 27/11 task requires history, Top-20 and real target. Without the bundle, the live demo of the core task is only a toy format example.
2. **Speaker reads unreadable numbers.** The script's 17-digit values will cause stumbling and do not match what the audience sees.
3. **Old version on the public link.** Render still serves the 21/11 build with toy/empty experiments until `review-2511` is merged into `main`.
4. **Phone view of E1 is broken.** Anyone opening the link on a phone sees overlapping text in the most important table.
5. **Questions triggered by UI artefacts.** The false "Differs" on Train through, developer file paths (`../tv4-real-bundle/...`) on the waiting screen, and terse English notes in VI mode can all draw awkward questions.
