## 8. Hard rules (from `AGENTS.md`, always apply)

1. Never invent numbers. Missing → `null` → "Not available yet" / "Chưa có"; inapplicable → "Not applicable" / "Không áp dụng".
2. Never derive a score from rank. Never recompute or redefine a metric (display rounding and MiB/GiB are allowed; the raw value stays in the JSON and the tooltip).
3. Keep planned (Dự kiến) and actual (Thực tế) separate. Do not flag symbolic planned values like `1..D-1` as different.
4. Label toy data; never mix toy and real in one table or chart. Toy data is now used only in `tests/fixtures/`.
5. Preserve artifact order; show original product IDs only; no technical IDs (0/1/2).
6. Always show the history and the actual next item.
7. No large data in Git (bundle, catalog, Parquet, checkpoints stay out). Every `public/*.json` < 300 KB.
8. Every number on screen comes from `public/*.json` generated by a script from the team repo; all UI text goes through `src/i18n.js` (`en` + `vi`).
9. Agents never push and never edit the team repo; the user pushes.

## 9. Gotchas seen in this project

- Agents report BLOCKED when:
  - VS Code opens only `tv4-demo-web`;
  - the team repo is on an old branch (`feature/tv4-demo`) instead of `main`;
  - a needed file sits at the repo root instead of `docs/`.

  Check these first.
- Copilot's Python interpreter can differ from the user's conda `(base)`. Install `matplotlib==3.10.1` into the interpreter the agent reports (`python3 -c "import sys; print(sys.executable)"`).
- Python tests assume the team repo at `../Big-Data`.
- An agent once ran an audit on **uncommitted** local changes. Always verify what is actually on GitHub (`git clone` + `git log`) before judging.
- Automated checks have missed visual problems twice: E1 text overlap at 375 px, raw i18n keys and chart label overlap. Always look at screenshots, and scan rendered text for i18n key names.
- `git switch` to a branch fails if another worktree holds it. Push with `git push origin HEAD:<branch>` instead.
- The 25/11 table-template task belongs to **TV5**, not TV4. TV4 owns figures and captions.
