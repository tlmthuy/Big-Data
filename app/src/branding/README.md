# Optional branding images

| Filename | Recommended dimensions | Maximum size |
| --- | --- | --- |
| `logo.png` | About 160 × 160 px | 50 KB (50,000 bytes) |
| `cover.jpg` | About 1600 × 400 px | 300 KB (300,000 bytes) |

Add either file to this directory before building. The header renders the logo only when the file exists. The banner appears only when the cover file exists. The build rejects files above the size limits.

Use self-made or royalty-free images. No third-party logos or copyrighted photos.
