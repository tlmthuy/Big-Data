
# Figures — Big Data Project

## 1. Purpose

This directory stores figures and visualizations
used in the final project report and presentation.

## 2. Planned Figures

### E1 — Model Comparison
- Recall@20 comparison
- NDCG@20 comparison
- Training and inference time

### E2 — Dataset Size Benchmark
- Runtime across 10%, 25%, 50%, 100% subsets
- Memory usage across dataset sizes

### E3 — Resource Benchmark
- Runtime under different resource configurations
- Throughput and memory usage

### E4 — CSV vs Parquet
- File size comparison
- Data loading and preprocessing time

### E5 — Scalability
- Runtime versus dataset size
- Runtime per million events
- Bottleneck analysis

## 3. Figure Requirements

Each figure should include:
- Descriptive title
- Clearly labelled axes and units
- Legend where applicable
- Source run_id
- Caption explaining the result

## 4. Data Source

All figures will use experiment metrics confirmed
by TV2 and logs provided by TV3.

No experimental results should be fabricated.
